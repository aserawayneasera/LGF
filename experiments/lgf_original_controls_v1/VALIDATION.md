## Results

Eleven tests passed on CPU with torch 2.10.0 and torchvision 0.25.0:

1. Exact native LGF block output equality and forward restoration after an error.
2. Exact manuscript fixed-control equations, with a hook proving the gate head
   is skipped for uniform, no_gate, and fixed-alpha controls.
3. Exact swap and joint image/channel shuffle formulas and reproducible shuffling.
4. Gate parameter counts exclude local/global branches and residual gamma.
5. Rejection of unsupported model architectures and mixed suite names.
6. Exact numerical agreement with all nine recovered notebook controls.
7. Correct handling of negative paired deltas and missing standard deviations.
8. A real RetinaNet LGF architecture with synthetic data: strict checkpoint
   loading, every manuscript control, nonempty predictions, export, unchanged
   checkpoint bytes, resume without repeated evaluation, and rejection of wrong
   metadata or changed predictions. This pipeline smoke check used a 64-pixel
   model transform for speed, isolated inside the test.
9. Original notebook checkpoint metadata and mAP selection enforcement.
10. Detection of changed native metrics relative to saved metrics.
11. Three-seed aggregation with mean, sample standard deviation, and correctly
    paired control-minus-native differences.

An additional compatibility check used the actual recovered
`reviewer34_compare.py` loader and inference adapter at the original 800/1333
transform settings. A synthetic LGF checkpoint with nonempty detections produced
exactly identical boxes, scores, and labels from the Reviewer34 adapter and the
new evaluator. See `validation/reviewer34_adapter.json` and its log.

The full unit/integration test log is `validation/tests.log`.

## Scope

These are software checks, not new research results. The user's real trained
checkpoints, real evaluation datasets, and Atlantis GPU were unavailable in this
session. CUDA numerical behavior, real AP reproduction, full-grid duration, and
GPU timing therefore have not been measured here.

The `check` action performs strict loading and dataset checks on Atlantis. The
`run` action additionally verifies exact native block equivalence on real inputs,
checks saved native AP when matching reference metadata exists, and checks
checkpoint/model-state integrity. A mismatch stops evaluation rather than
silently producing an incomparable table.

The manuscript and notebook suite definitions differ. This package does not
claim the old published Table S6 numbers were generated by either particular
implementation; determining that requires the original run records. Use the
explicitly recorded equations when reporting the newly generated results.
